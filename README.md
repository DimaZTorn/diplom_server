# Дипломный проект: Серверная часть (FastAPI)

  Cерверное приложение на базе **FastAPI** для анализа текстовых данных с использованием локальной языковой модели **RuBERT** (`zero-shot-classification`) и сохранением результатов в базу данных **PostgreSQL**.

## Установка и настройка

### 1. Настройка базы данных и окружения (.env)
  Для работы приложения необходима запущенная СУБД **PostgreSQL**.
  
  1. Создайте пустую базу данных.
  2. Создайте файл .env на основе примера из .env.example и заполните своими данными
  
  *При первом старте сервера таблицы в базе данных будут созданы автоматически.*

### 2. Подготовка модели RuBERT

  1. Скачайте архив с весами модели по ссылке: 'https://disk.yandex.ru/d/NfrBaqm3sguXbA'
  2. Распакуйте содержимое архива в папку `rubert_finetuned` в корне проекта.

---

## Запуск приложения

  1. **Активируйте виртуальное окружение** (если не активировано):
     ```bash
       # Для Windows:
       .venv\Scripts\activate
     
       # Для macOS/Linux:
       source .venv/bin/activate
     ```
  
  2. **Запустите веб-сервер Uvicorn**:
     ```bash
       uvicorn main:app --reload
     ```
  
  3. **Интерфейс и тестирование**:
     После запуска сервер начнет слушать запросы. FastAPI автоматически генерирует интерактивную документацию, где можно протестировать эндпоинты:
     http://127.0.0.1:8000/docs

---

## Основные эндпоинты
  
  * `POST /analyze` — Принимает текст, выполняет zero-shot классификацию с помощью RuBERT по заданным категориям и возвращает топ-3 результата с оценками уверенности.
  * `POST /auth` — Модуль авторизации пользователей.
  * `POST /save_text_data` — Сохранение обработанных текстовых данных в базу данных.
